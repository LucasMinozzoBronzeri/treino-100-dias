Gym Bronze v7.0.0 — Central do Treino de Hoje

Reorganização principal:
- Unifica Ajuste rápido e Versões do treino em uma única central:
  "Treino de hoje" / "Ajuste treino hoje".

Na central:
- Iniciar treino de hoje
- Editar treino fixo
- Escolher versão temporária:
  - Completo
  - Rápido
  - Academia cheia
  - Sem máquina
  - Leve / recuperação
- Escolher ajuste de situação:
  - Estou sem tempo
  - Estou muito cansado
  - Estou com dor/desconforto
  - Academia cheia
  - Quero trocar exercício

Regras:
- Versões e ajustes valem só para o dia.
- O treino original/fixo não é alterado.
- Ao finalizar, versão/ajuste usados ficam registrados no histórico e no payload da IA.
- Depois de finalizar o treino, o app limpa ajuste e versão ativos.

Atalhos atualizados:
- Tela Hoje: Ajuste treino hoje
- Aba Treinos: Treino de hoje
- Modal do treino: Ajuste treino hoje
- Menu rápido: Treino de hoje

Sem SQL novo.
Backend sem mudança obrigatória.
