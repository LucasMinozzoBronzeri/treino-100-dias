Gym Bronze v6.9.0 — Versões temporárias do treino

Novidades:
- Versões do treino para o dia:
  - Completo
  - Rápido
  - Academia cheia
  - Sem máquina
  - Leve / recuperação
- A versão aplicada vale só para o treino do dia.
- O treino original não é alterado.
- Ao finalizar o treino, a versão usada fica registrada no histórico do treino.
- Na próxima vez que o mesmo treino aparecer, ele volta normal.
- A versão entra no payload de IA como workoutVariant.
- Atalhos:
  - Tela Hoje: Versões
  - Aba Treinos: Versões
  - Modal do treino: Versões
  - Menu rápido: Versões

Sem SQL novo.
Backend sem mudança obrigatória.
